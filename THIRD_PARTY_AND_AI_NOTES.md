# AI models, APIs, libraries and external services used

## AI model / API
None. No external AI model, hosted service or dataset is used. No model weights are downloaded.

## Python libraries (see `requirements.txt`)
| Library | Purpose | License |
|---|---|---|
| Pillow | image loading, drawing, frame composition | HPND (PIL) |
| NumPy | audio synthesis/mixing, saliency | BSD-3 |
| imageio-ffmpeg | supplies an ffmpeg binary | BSD-2 (ffmpeg binary: LGPL/GPL build) |
| Flask (+ Werkzeug, Jinja2) | optional web UI | BSD-3 |
| pyttsx3 | offline voice-over | MPL-2.0 / LGPL |

## External programs
| Program | Purpose | Required? |
|---|---|---|
| ffmpeg | H.264/AAC encoding and muxing | Yes (bundled via imageio-ffmpeg, or system install) |
| espeak-ng (Linux/Windows) / `say` (macOS) | offline voice-over | Optional; video is made without narration if absent |

## Assets
* **Fonts:** Poppins (SIL OFL 1.1) and DejaVu Sans (fallback) in `assets/fonts/`, see `FONT_LICENSES.md`.
* **Photos:** the six sample images are *synthetic illustrations generated by `scripts/make_sample_images.py`*.
* **Music:** synthesised at run time by `pvg/audio.py` (original, royalty-free). Users may pass their own file with `--music-file`.
* **Data:** all sample data is fictional; the contact details use `example.com` and a placeholder phone number. No passwords, API keys or customer data are included.
